# Regenduo – Healthcare Website

A responsive healthcare website concept designed to provide a professional digital presence for a medical service provider. Regenduo presents healthcare services, essential information, patient feedback, and health-related resources through an accessible and user-friendly interface.

The website is designed to help visitors explore available medical services, learn about the organization, and access an appointment inquiry interface.

**Live Demo:** [Regenduo Website](https://ayoglow01.github.io/regenduo1/)

## Features

- **Healthcare Overview** – Introduction to the healthcare organization and its approach to patient care.
- **Services Showcase** – Presentation of primary care, emergency care, pharmaceutical care, nutritional support, laboratory and diagnostic services, and physical and mental therapy.
- **Appointment Interface** – Dedicated section with an appointment request form.
- **Patient Testimonials** – Display of customer feedback and experiences.
- **Health Resources** – News and informational content covering health-related topics.
- **Responsive Navigation** – Navigation menu with mobile menu controls.
- **Theme Toggle** – Light and dark mode interface controls.
- **Interactive Elements** – Scroll-triggered animations, loading screen, and interface interactions.

## Technology Stack

| Category | Technologies |

## Getting Started

Regenduo is a frontend project built with standard web technologies and does not require a framework or package installation.

### Run Locally

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate into the project directory:

```bash
cd <project-directory>
```

3. Open `index.html` in your browser, or use a local development server such as VS Code Live Server.

## Implementation Note

The appointment section provides a frontend form interface. A backend or form submission service is required to process real appointment requests.

## Deployment

The project is deployed using Netlify.
